# Public index styling and icons

`ruleset-index.css` styles the standalone directory index generated by `Build/build-public.ts`.

- **Visual system**: [coss ui](https://coss.com/ui) ([source](https://github.com/cosscom/ui)). Its design tokens and the Button, Badge, Kbd, Input, Frame and Command styles are rewritten as plain CSS for a static page; no React, Base UI or Tailwind code ships with the index. coss ui is distributed under the MIT License reproduced below.
- **Icon set**: [Tabler Icons](https://tabler.io/icons) (MIT License, 24×24 grid, `1.5px` stroke), inlined as `<defs><symbol>` entries in `Build/build-public.ts` and tinted via `currentColor`.
- **Directory tree inspiration**: Native `<details>` / `<summary>` directory browsing inspired by [SukkaW/Surge](https://github.com/SukkaW/Surge) (AGPL-3.0).
- **Local license**: [AGPL-3.0](../../LICENSE).

No external fonts, stylesheets, icon CDNs, or third-party scripts are referenced by the generated `index.html`.
