# Public index styling

The NRRule directory index CSS in `ruleset-index.css` and its tree markup are copied or adapted from Sukka's [SukkaW/Surge index generator](https://github.com/SukkaW/Surge/blob/6373d9aca136bf6b8f4ad091baebf50a8f088d4a/Build/build-public.ts), as observed at [ruleset.skk.moe](https://ruleset.skk.moe/) on 2026-10-08.

- Local license: [AGPL-3.0](../../LICENSE).

The retained styling includes the system font stack, responsive container sizes, light and dark colors, and inline file/folder SVGs. NRRule changes the page identity, author and source links, service URLs, build timestamp, and directory contents to match MirrRule. The rendered page links to MirrRule's source repository and its license.

The upstream site's branded favicons and Cloudflare-injected challenge scripts are not part of the NRRule index assets. Keep source and license attribution when modifying or distributing this styling.
