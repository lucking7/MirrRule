# Public index styling and icons

`ruleset-index.css` styles the standalone directory index generated by `Build/build-public.ts`.

- **Icon set**: [Tabler Icons](https://tabler.io/icons) (MIT License, 24×24 grid, `1.5px` stroke), inlined as `<defs><symbol>` entries in `Build/build-public.ts` and tinted via `currentColor`.
- **Directory tree inspiration**: Native `<details>` / `<summary>` directory browsing inspired by [SukkaW/Surge](https://github.com/SukkaW/Surge) (AGPL-3.0), redesigned with bespoke tokens, Tabler icons, an architectural masthead, inline filtering, and progressive-enhancement URL copying.
- **Local license**: [AGPL-3.0](../../LICENSE).

No external fonts, stylesheets, icon CDNs, or third-party scripts are referenced by the generated `index.html`.
